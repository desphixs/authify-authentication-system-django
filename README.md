# Build Authify: Authentication System

### Project Description

You are going to build Authify, a logic first user dashboard with a pure authentication system. You will start by setting up a custom user model so people can log in with their email address instead of a username. Then, you will write custom registration forms to securely hash passwords and save new users. After that, you will build the standard login and logout flows to manage user sessions. Finally, you will create a secret dashboard page and use a simple rule to automatically kick out anyone who is not logged in. You will write everything using raw Django code and function based views so you understand the exact flow of data and security.
